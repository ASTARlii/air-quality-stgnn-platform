# 接口说明

> 对应开题报告 3.3（2）三类 AI 服务。状态：已完成，契约以 `docs/openapi.json` 为准。

## 1 通用约定

- 前缀：`/api/v1`
- 认证：单管理员 Bearer Token（仅管理类接口）
- 分页：`?page=1&size=20`，返回 `{items, total, page, size}`
- 错误体：

```json
{ "code": "PRED_INPUT_TOO_SHORT", "message": "输入窗口不足 24 小时", "detail": {} }
```

- 错误码分段：`PRED_*` 预测、`NET_*` 网络、`TASK_*` 任务、`DATA_*` 数据

## 2 预测服务

### POST /predictions

请求：

```json
{ "station_id": "1001A", "pollutant": "pm25", "steps": [1,3,6,12,24], "as_of": "2024-12-31T23:00:00" }
```

响应：

```json
{ "station_id": "1001A", "pollutant": "pm25", "series": [{"h":1,"value":45.2,"lo":40.1,"hi":50.3}], "model_id": "gw_pm25_v3", "latency_ms": 18, "as_of": "2024-12-31T23:00:00" }
```

> `lo/hi` 仅在启用预测区间（可选增强）时返回。
>
> `as_of`（请求）：按北京时间解释（带时区偏移会先换算到北京时间），取不晚于该时刻的最近整点作为输入窗口末；缺省用最新 24 小时。早于数据起点或窗口不足 24 小时返回 400，晚于数据末尾按最新窗口处理。响应中的 `as_of` 为实际使用的窗口末时刻。

## 3 解释服务

### GET /networks?from=&to=&pollutant=

返回节点、边与指标（模块度、中心性、与模型网络的一致性指标）。

### POST /networks/recompute

提交重算任务，返回 `task_key`；相同参数重复提交返回同一任务。

### GET /trace?station_id=&pollutant=&from=&to=

返回污染来源候选：

```json
{ "target": "1001A", "candidates": [{"station_id":"1002A","score":0.82,"lag_h":2,"upwind":true}] }
```

### GET /key-stations?top=10

返回按中心性 + 超标频次排序的关键站点清单。

## 4 分级服务

### GET /grading?station_id=&pollutant=

```json
{ "station_id":"1001A", "pollutant":"pm25", "level":"轻度污染", "basis":"GB 3095-2012 二级", "values":{"h1":45,"h3":52} }
```

## 8 接口实现状态（2026-11-27）

| 接口 | 实现 | 数据源 |
| --- | --- | --- |
| POST /predictions | ✅ | Graph WaveNet 真模型（ModelPool 常驻） |
| GET /grading | ✅ | 预测 + GB 3095-2012 分级纯函数 |
| GET /stations | ✅ | `data/raw/stations.csv`（24 站元信息） |
| GET /networks | ✅ | 转移熵 + 滞后相关融合网络（磁盘缓存，未命中返回 202） |
| POST /networks/recompute | ✅ | 幂等任务队列（hash 键 + 状态机） |
| GET /trace | ✅ | 沿有向边反向溯源（关联非因果） |
| GET /key-stations | ✅ | 度 / PageRank / 介数 综合中心性 |
| GET /tasks, /tasks/{key} | ✅ | 内存任务队列 |
| GET /datasets, /models | ✅ | 模型池/数据集元信息 |
| GET /health | ✅ | — |

网络构建的显著性检验：对转移熵与滞后相关分别做相位随机化 surrogate test（默认 100 次），再用 Benjamini-Hochberg FDR（α=0.05）校正多重比较。实测窗口 2024-10-01 ~ 2024-11-30（1441h）下 552 条有向边中 330 条通过 FDR，构建耗时约 95 s（异步任务，结果落盘缓存）。

## 9 限流与超时约束

以下为接口约束约定。当前演示版本未启用限流中间件，部署时按本表接入令牌桶与超时兜底；触发限流返回 `429 RATE_LIMITED`，超时返回 `504 GATEWAY_TIMEOUT`。

| 接口 | 限流（单客户端） | 超时 | 说明 |
| --- | --- | --- | --- |
| POST /predictions | 30 req/s，突发 60 | 2 s | 模型池常驻，20 并发实测 P95 172–300 ms |
| GET /grading | 60 req/s | 1 s | 纯函数分级，无 I/O |
| GET /stations | 60 req/s | 1 s | 静态元信息，可长缓存 |
| GET /networks | 10 req/s | 30 s | 命中磁盘缓存毫秒级；未命中返回 202 |
| POST /networks/recompute | 2 req/min | 异步 | 立即返回 task_key，单任务上限 600 s |
| GET /trace | 20 req/s | 5 s | 沿有向边反向遍历 |
| GET /key-stations | 20 req/s | 5 s | 中心性预计算，读取缓存 |
| GET /tasks、/tasks/{key} | 60 req/s | 2 s | 轮询接口，前端建议 2 s 间隔 |
| GET /datasets、/models | 10 req/s | 5 s | 管理视图 |
| 全局 | — | 60 s | 超过即断开连接并写入异常日志 |

## 10 前端契约同步

- 契约唯一来源：`docs/openapi.json`，由 FastAPI `app.openapi()` 导出，接口变更时同步归档；
- 前端用 `openapi-typescript` 生成只读类型，禁止手写响应体接口：

```bash
npx openapi-typescript docs/openapi.json -o web/src/api/schema.d.ts
```

- 请求封装统一在 `web/src/api/`，其返回类型引用 `schema.d.ts` 的 `paths`，字段改名时编译期即报错；
- 提交前或 CI 中执行 `npx openapi-typescript docs/openapi.json -o web/src/api/schema.d.ts` 并检查 `git diff --exit-code web/src/api/schema.d.ts`，契约与类型不一致即失败；
- 变更顺序遵循 `docs/09-开发规范.md` §6：先改接口文档与 OpenAPI，再生成类型，最后改页面。

> 当前前端请求封装为手写类型，生成类型接入列入后续迭代，约定已在此固化。
