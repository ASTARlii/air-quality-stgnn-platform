# 接口说明

> 对应开题报告 3.3（2）三类 AI 服务。状态：骨架，正式以 OpenAPI 导出为准。

## 1 通用约定

- 前缀：`/api/v1`
- 认证：单管理员 Bearer Token（仅管理类接口）
- 分页：`?page=1&size=20`，返回 `{items, total, page, size}`
- 错误体：

```json
{ "code": "PRED_INPUT_TOO_SHORT", "message": "输入窗口不足 24 小时", "detail": {} }
```

- 错误码分段：`PRED_*` 预测、`NET_*` 网络、`TASK_*` 任务、`DATA_*` 数据

## 2 预测服务

### POST /predictions

请求：

```json
{ "station_id": "1001A", "pollutant": "pm25", "steps": [1,3,6,12,24], "as_of": "2024-12-31T23:00:00" }
```

响应：

```json
{ "station_id": "1001A", "pollutant": "pm25", "series": [{"h":1,"value":45.2,"lo":40.1,"hi":50.3}], "model_id": "gw_pm25_v3", "latency_ms": 18 }
```

> `lo/hi` 仅在启用预测区间（可选增强）时返回。

## 3 解释服务

### GET /networks?from=&to=&pollutant=

返回节点、边与指标（模块度、中心性、与模型网络的一致性指标）。

### POST /networks/recompute

提交重算任务，返回 `task_key`；相同参数重复提交返回同一任务。

### GET /trace?station_id=&pollutant=&from=&to=

返回污染来源候选：

```json
{ "target": "1001A", "candidates": [{"station_id":"1002A","score":0.82,"lag_h":2,"upwind":true}] }
```

### GET /key-stations?top=10

返回按中心性 + 超标频次排序的关键站点清单。

## 4 分级服务

### GET /grading?station_id=&pollutant=

```json
{ "station_id":"1001A", "pollutant":"pm25", "level":"轻度污染", "basis":"GB 3095-2012 二级", "values":{"h1":45,"h3":52} }
```

## 5 任务服务

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /tasks | 提交任务（幂等） |
| GET | /tasks/{task_key} | 查询状态与进度 |
| GET | /tasks?status=running | 列表 |

## 6 平台管理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /datasets | 上传并登记数据集版本 |
| GET | /datasets | 版本列表 |
| GET | /models | 模型版本列表 |
| GET | /logs | 关键操作与异常日志 |
