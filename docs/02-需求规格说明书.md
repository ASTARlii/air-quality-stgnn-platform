# 需求规格说明书

> 对应开题报告 3.1 研究目标、3.3（1）需求分析、（4）非功能需求。状态：已完成（2026-11-28），待确认事项已闭环。

## 1 引言

### 1.1 编写目的
明确系统边界、用户角色、功能与非功能需求，作为设计、开发与验收的依据。

### 1.2 系统范围
面向单一城市（北京）国控监测站点的空气质量预测与污染关联分析系统，提供多步浓度预测、分级提示、关联网络与来源候选分析，支持单机部署与演示。

### 1.3 术语
| 术语 | 说明 |
| --- | --- |
| 多步预测 | 一次推理输出未来 1/3/6/12/24 小时浓度 |
| 关联网络 | 基于转移熵、滞后相关与风场先验构建的有向统计网络 |
| 忠实度 | 移除高权关联后预测误差的上升程度，衡量解释是否真实起作用 |
| 分级提示 | 按 GB 3095-2012 二级浓度限值对预测浓度分级，非官方预警 |

## 2 用户角色

| 角色 | 关注点 | 使用频率 |
| --- | --- | --- |
| 数据分析者 | 预测精度、关联结构、来源候选 | 高 |
| 环保业务人员 | 分级提示、重点管控站点 | 中 |
| 系统管理员 | 数据与模型版本、任务与日志 | 低 |

## 4 功能需求

- FR-1 数据预处理：缺失填充、MAD 异常检测、归一化、按年切分、质量自检
- FR-2 预测服务：4 个单输出模型（PM2.5/PM10/NO2/O3），输入 9 维、窗口 24h，输出 1/3/6/12/24h
- FR-3 解释服务：关联网络构建、结构一致性指标、忠实度检验、反向溯源、关键站点遴选
- FR-4 分级服务：按 GB 3095-2012 二级限值实时分级
- FR-5 平台管理：数据集与模型版本登记、任务提交与状态、日志查看
- FR-6 可视化：热力图、时序曲线、网络拓扑、指标面板、多视图联动、筛选导出

## 5 非功能需求

| 编号 | 指标 | 目标 |
| --- | --- | --- |
| NFR-1 | 首屏加载 | ≤ 3 s |
| NFR-2 | 预测/分级接口 P95 | ≤ 500 ms |
| NFR-3 | 关联网络重算 | ≤ 10 min，全程有进度 |
| NFR-4 | 并发 | ≥ 20（演示规模） |
| NFR-5 | 可复现 | 干净环境按 README 一次部署成功 |
| NFR-6 | 可维护 | 核心计算有单元测试，接口有统一错误码 |

## 6 验收标准

1. UC-01 ~ UC-09 全部通过功能测试；
2. NFR-1 ~ NFR-4 由性能测试报告佐证；
3. NFR-5 由部署复现记录佐证。
