# 实验记录规范

> 对应开题报告 6.3 实验设计（E1–E7）、6.4 评估指标。状态：骨架，开工即用。

## 1 run_id 命名

```
{日期}-{模型}-{污染物}-{种子}
例：20260105-gwnet-pm25-s42
```

- 模型代号：`gwnet` / `stgcn` / `lstm` / `xgboost` / `arima` / `mtgnn`
- 污染物：`pm25` / `pm10` / `no2` / `o3`（ARIMA、单站 LSTM 等单点基线同样按污染物记录）
- 种子：3–5 个固定值（如 42/43/44），保证可复现

## 2 目录组织

```
runs/{run_id}/
├── config.json        完整超参数与数据版本
├── metrics.json       MAE / RMSE / R2 / 各步长指标
├── train.log          训练日志
├── checkpoints/       按 epoch 保存（支持断点续训）
└── figures/           预测曲线、误差分布
```

## 4 实验与记录对照

| 实验 | 内容 | 记录要求 |
| --- | --- | --- |
| E1 | 主模型 vs 基线 | 每个模型 × 3–5 种子，报告均值 ± 标准差 |
| E2 | 空间结构消融（完整 / 距离图 / 纯 TCN） | 固定其余超参，仅改图结构 |
| E3 | 自适应 vs 静态图 | 记录三种图构建方式 |
| E4 | 预测时效衰减 | 分 1/3/6/12/24 h 报误差 |
| E5 | 四污染物泛化 | 4 个单输出模型分别记录 |
| E6 | 网络结构一致性 | 记录 Spearman、边重叠率、模块度、中心性一致性 |
| E7 | 解释忠实度 | 记录高权边移除 / 随机移除的 MAE 相对上升率、Jaccard |

## 5 复现要求

1. 每个 run 必须能由 `config.json` + 数据版本号 + 随机种子完整复现；
2. 超参变更必须体现在 config 中，不允许只改代码；
3. 结果表在论文中引用的每个数字，都要能追溯到 run_id。
